## 確定済み方針

### 活動の位置づけとリポジトリ間連携（確定、2026-06-06）

- 本活動（ユースケース設計＝user-review）は **A リポジトリ（cc-relative-info）で継続**する。評価対象である `gen-out`（生成 llms.txt 47 ターゲット）が A にあり、活動自体が確定前の内部検証＋メタ開発資産であるため。
- 確定した知見は **適宜 B リポジトリ（empty-can/LLMs）の運用・公開設計へ反映**する。
  - 反映済み事例: P0.1 round 2 の 7 シナリオ統合（`_workspace/agent-c-synthesis.md`）が確立した **CLAUDE.md 配置原則** → B のレイアウト設計（root CLAUDE.md 撤去・`.claude/CLAUDE.md` 一本化・content dir ナビの README.md 化）に 2026-06-06 反映済み。
- 将来 `gen-out` 由来の生成 llms.txt を B で公開する判断をする段階で、本活動自体を成果ごと B へ移すことを検討する（バックログ B-2 と同じ意思決定）。

### 出力先

- `LLMs/work/user-review/` 配下に集約
- 中間アウトプット: `LLMs/work/user-review/_workspace/`

### CLAUDE.md 原則（確定）

詳細は `_workspace/glossary.md` 第 4 章参照。要点:

- `CLAUDE.md` 系メンテナー文書は **利用者としての Claude には原則読まれるべきでない**
- 利用者の Claude が読むことはコンテキスト浪費以外のメリットがない
- Scenario 4（同居非メンテナー）では clone 時の自動侵食で**実害が具体的に発生**
- 読み手が**人間の利用者**の場合は害がなく、読まれてもよい

- **内容**: LLM 生成の narrative に手を加えず、別途用意した「ユースケース別キーワード辞書」と本文（`llms-full.txt`）を grep で照合し、ヒットしたキーワードを **narrative 末尾にカンマ区切りで羅列**する仕組み
- **起源**: 2026-05-28 セッション末尾の作業指示者アイデア。B-10pre 拡張調査が「Anthropic Batch + retry + grep validator」を推奨した直後の発想転換
- **核心の利点**:
  - LLM 生成品質への要求が現状維持で済む（「人が読んで概要が理解できる」レベルで OK）
  - keyword inclusion が**完全に決定論的**（grep + lookup なので LLM の non-determinism から完全独立）
  - retry コストがゼロ
  - 辞書を更新するだけで網羅性を段階的に強化できる
- **焦点が移る点**:
  - ユースケース別キーワード辞書の**収集方法**
  - 辞書の**ライフサイクル管理**（追加・削除・更新トリガ）
- **収集方法のアイデア（作業指示者提案）**:
  - 主参照者が Claude Code であることを利用し、**複数の Claude Code モデルに「このユースケースで `llms.txt` を grep するなら何のキーワードを使うか」をヒアリング**する形で初期辞書を構築
  - 人の利用者は grep 以外の手段も併用するため、Claude Code カバーで実用上の主要ユースケースは網羅できる、という見立て
- **B-10 / B-11 への影響**:
  - **本アプローチが採用される場合、B-10（retry-based guarantee）と B-11（narrative 安定化）は不要になる可能性が高い**
  - B-10pre 調査の結論（Anthropic Batch + grep validator + retry）が大幅にシンプル化される（retry 不要、validator は post-process 内に含まれる）
- **未検討事項**:
  - 辞書のフォーマット（target 別 / ユースケース別 / 階層構造）
  - サーベイ用 prompt の設計（複数モデルでの集約・合議方法）
  - 末尾タグ行の構造（Claude Code が混乱しない記述方式）
  - 辞書のバージョン管理（target が追加されたら、CC のモデル更新があったら、利用者からのフィードバックがあったら、等）
- **優先度**: 高（B-10 / B-11 を置き換える可能性。次セッションで詳細検討候補）
