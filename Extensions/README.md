# Extensions

Claude Code を拡張する Skill / Rule / Plugin（公式・サードパーティ問わず）のインデックス情報を集約するフォルダ。

## 目的

1. GitHub 上で公開されている有用な Skill・Rule・Plugin について、インデックス的な情報を集約する（サマリ・独自観点からの評価を含む）
2. インデックスを元に、現在利用している / 作成を検討している Skill・Rule・Plugin が既に存在しているかを確認できる仕組みを構築する

## 現状

フォルダのみ作成済み。インデックスフォーマット・収集対象一覧・評価軸・既存確認スクリプトは未整備。
