## 1. 基準スナップショット

**commit ハッシュで固定してある。** 手元の作業コピーが更新・削除・移動されても、下の `git show` で当時の断面をバイト単位で復元でき、**パス・行番号・見出しはその断面の中で変わらない**。

| 項目 | 値 |
|---|---|
| リポジトリ | `https://github.com/empty-can/LLMs` |
| **commit** | `5f51174830a6109f6c27c1eeae6dd98de6f65dde` |
| commit の日付 | 2026-11-21（定期取り込み） |
| パス | `official-llms-txts/code.claude.com/docs/llms-full.txt` |
| **blob** | `b992c5797122b5fccf36c9b5be64037eaa290a80` |
| 規模 | **130,625 行** |
| CLI の相当する版 | **2.1.330**（changelog の最新の節） |
| 参照の形 | **絶対行番号 ＋ ページ名 ＋ 見出し** |

**復元の手順**:

```bash
git -C <LLMs のクローン> show 5f51174830a6109f6c27c1eeae6dd98de6f65dde:official-llms-txts/code.claude.com/docs/llms-full.txt > bs.txt
sed -n '<行番号>p' bs.txt
```

- ページの区切りは `Source: https://code.claude.com/docs/en/<ページ名>` の行である。ページの先頭の行は `grep -n '^Source: https://code.claude.com/docs/en/' bs.txt` で一覧できる
- `plugins/create`・`plugins/install`・`plugins/mods/overview` の 3 ページは、この取込に 2 回ずつ収録されている（本文は同じ）。行番号で引くときは**後ろの出現**を採る。下の表が引く行は、この 3 ページに含まれない
- changelog の行は、直前の版の見出し（`**2.1.x**` の行）で、どの版の記述かを決めた
