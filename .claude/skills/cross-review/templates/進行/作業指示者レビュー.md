## 記入の手引き（記入の後は消してよい）

### ラベル

| ラベル | 意味 |
|---|---|
| **CRITICAL** | 直さないと承認できない（差し戻しの水準） |
| **IMPORTANT** | 直してほしい。品質を著しく損なう |
| **SUGGESTION** | 任意の改善の提案 |
| **POSITIVE** | 良い判断・維持してほしい点 |

### 1 件の書き方

```
### H-<ラベルの頭文字><連番>: <短いタイトル>
**観点**: 任意（例: 計画の遵守 / 範囲の整合 / 用語の統一）
**該当箇所**: 節（横断的な指摘なら「全体」）
**指摘内容**:
* 概要: 何が問題か / 何を良いと感じたか
* 問題点: 本質的な問題点（任意）
* 影響: 直さないことによる影響と範囲（任意）
**期待する対応**: どう直してほしいか（CRITICAL・IMPORTANT は必須）
```

- 接頭辞 `H-` は作業指示者（人間）の指摘の意。代理のレビューア（作業指示者+人間読み手観点）の `U-` と区別する。連番は同じラベルの中の通し番号（`H-C1`・`H-I1`…）
- 既存の指摘への補足は、見出しに参照を入れる（例: `### H-I1: 論理整合性 I3 への補足`）。本文では `[関連: 論理整合性 C1]`・`[既存の指摘に同意]`・`[既存の指摘に反対]`・`[既存の指摘を補強]` のように書くと、Claude が紐付けやすい

### 既存の指摘への態度表明

各報告書の指摘の末尾の「作業指示者の態度表明」の欄に書く。

| 態度 | 意味 |
|---|---|
| 採用 | 指摘を受け入れ、修正案を当てる |
| 条件付き採用 | 修正案を一部変える・条件を加えて採る |
| 差戻し | 執筆者に追加の情報・再検討を求める |
| 保留 | 今は判断しない。意思決定型の保留に限る（今決めなくても活動に影響が無い、または活動の範囲の外、のどちらかを根拠にする） |
| 却下 | 指摘を受け入れない。作業指示者に固有の事情（制約・範囲の外）で指摘が無効と分かったときに限る |

POSITIVE には「維持／維持＋強化／横展開／維持不要」で答える。
