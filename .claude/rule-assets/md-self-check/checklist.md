# `.md` のセルフチェックのチェックリスト

rule `.claude/rules/md-self-check.md` から読まれる。新しい文書の執筆と、内容に関わる修正のときに使う（機械的な追記・表記や誤字の訂正だけのときは使わない。1 回の見直しでよい）。巡の上限と終わり方の数字の正は、このファイルだけにある。

## 1. 巡の数と終わり方

- 見直しを反復する。上限は 3 巡。直近の 1 巡で新しい問題が 0 件なら終える
- 重大な問題（読み手の判断や実行を誤らせるもの、事実と合わないもの）が残る間は、上限を超えて続け、超えたことを報告する

## 2. 巡ごとに見ること

1. 直した文と食い違うほかの箇所（直した事項の語で、文書の全体を Grep する。差分の外も探す）
2. 書いた手順・数字・参照先（ファイル・節・コマンド・引数）が事実と合うか（参照先は自分で開いて確かめる）
3. 読み手に残る疑問（前提の抜け、定義の無い語、止まったときの次の手）
4. 決まっていないことを、新しく作っていないか（未決の選択・新しい節・推測の断定）

## 3. 報告

- 巡の数と、巡ごとに見つけたもの・直したものを、報告（最後の返答、または報告書）に書く。新しい問題が 0 件だった巡も書く

## 4. クロスレビューの担当

- クロスレビューのレビューアは、このチェックリストではなく `.claude/skills/cross-review/references/reviewing.md` §5 に従う
- クロスレビューの反映の担当は、このチェックリストに `.claude/skills/cross-review/references/revising.md` §3.3 の固有の見ることを足す
